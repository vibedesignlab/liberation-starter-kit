# Lightweight anatomy tuning

Apply the source anatomy as an operating model, not as a collection of recognizable surfaces.

## Brand-grammar relationships

- **retain the job:** keep the source rule's semantic purpose when it fits the new product;
- **tune the expression:** adjust hierarchy, intensity, rhythm, modality, or context for the target;
- **replace the mechanism:** use a target-native mechanism when the source expression would be false, irrelevant, or overly imitative;
- **add what is missing:** introduce only what the target product needs to be understood on the landing page.

For each important transfer decision record:

`source signal → semantic job → chosen relationship → target direction → source boundary`

Do not automatically copy a logo, name, slogan, proprietary interface, recognizable product silhouette, or campaign frame. If the user explicitly wants to reuse or closely reference a source token, state that relationship transparently rather than presenting it as an original discovery.

## Design-token relationships

Use only these values in the final token records:

| Relationship | Meaning |
|---|---|
| `keep` | Carry a source-observed value or operating relationship into the directional concept because the user requested it. Preserve its observed scope. |
| `tune` | Keep the source role but change the value, contrast, scale, rhythm, or channel behavior for the new direction. |
| `new` | Define a target-native token direction without relying on a source value. |

Tokens stop at color, typography, spacing, layout, shape/border/radius, and optional motion. They guide a landing page and moodboard; they do not constitute a component system.

## Visual boundaries

Keep these layers distinct even in a short report:

- **key visual:** the relationship among message, type, color, graphic form, product, UI, image, and format;
- **brand image:** the world, people, atmosphere, camera, light, material, and color treatment;
- **product image:** how a product or interface is presented to explain form, use, detail, state, or proof;
- **product visual traits:** what the physical object, digital interface, or hybrid product itself looks like and how it is understood.

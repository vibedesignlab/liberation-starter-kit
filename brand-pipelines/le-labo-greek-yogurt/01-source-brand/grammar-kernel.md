# Source grammar kernel

> Source-only artifact. Target categories and downstream mapping are forbidden.

## GK-01 — 기록 가능한 중립 구조

- Input condition: 감각적이고 개인적인 제품을 하나의 가족으로 제시할 때
- Transformation: 중립 용기와 분류형 정보 구조를 고정하고 이름·숫자·날짜·개인 표식만 통제해 바꾼다.
- Intended effect: 체계의 신뢰성과 개인 경험을 동시에 만든다.
- Evidence IDs: EV-003 EV-013 EV-014 EV-015 EV-018 EV-020 EV-021
- Connected claim IDs: CL-002 CL-004 CL-009 CL-011
- Confidence: high
- Alternative explanation: 중립 구조는 전자상거래 가독성과 생산 효율의 결과일 수 있다.
- Exception and scope: 현재 fragrance, home, body, discovery, refill의 공식 표본 범위다. 용기 실루엣 자체는 불변항이 아니다.
- Protected source expression: Le Labo 워드마크, 약국형 라벨, 향명+숫자는 직접 복제하지 않는다.
- Acceptance test: 반복 제품에서도 상태와 개체 차이가 정보로 즉시 구분된다.
- Rejection test: 장식 변주가 가족성을 무너뜨리거나 개인화가 임의 장식으로만 보인다.

## GK-02 — 장면에서 사실로 이동

- Input condition: 감각을 설명하면서 구매 판단에 필요한 사실을 제공할 때
- Transformation: 장소·몸·기억의 장면으로 시작하고 구성·형식·용량·성분·관리 정보를 단계적으로 공개한다.
- Intended effect: 상상과 신뢰를 한 흐름 안에 유지한다.
- Evidence IDs: EV-001 EV-002 EV-004
- Connected claim IDs: CL-001 CL-003
- Confidence: high
- Alternative explanation: 일반적인 향수 카피 관습일 수 있다.
- Exception and scope: FAQ와 오류·관리 문구는 사실을 먼저 제시한다.
- Protected source expression: “We believe” 반복과 고유 향 서사는 복제하지 않는다.
- Acceptance test: 감각 장면 뒤에도 필수 사실과 한계를 찾을 수 있다.
- Rejection test: 시적 문장만 남거나 명세가 첫 인상을 모두 점유한다.

## GK-03 — 제작 행동을 가치의 근거로 사용

- Input condition: 장인성 또는 재료 기원을 주장할 때
- Transformation: 완성된 포즈 대신 손·작업자·도구·원료가 실제 행동하는 장면을 보여 준다.
- Intended effect: 고급감을 추상 형용사가 아니라 관찰 가능한 노동으로 바꾼다.
- Evidence IDs: EV-007 EV-008 EV-009 EV-036 EV-037 EV-038 EV-039
- Connected claim IDs: CL-006 CL-007
- Confidence: high
- Alternative explanation: About 페이지의 다큐멘터리 장르에 한정될 수 있다.
- Exception and scope: PDP 사실 사진은 완전한 제품을 우선한다.
- Protected source expression: 고유 랩과 장인 다큐멘터리 장면은 재연하지 않는다.
- Acceptance test: 누가 무엇을 어떻게 다루는지 한 장면에서 설명할 수 있다.
- Rejection test: 작업자가 소품처럼 서 있거나 손과 도구가 제품을 가린다.

## GK-04 — 촉각적 정보 매체를 그래픽 장치로 전환

- Input condition: UI, 편집, 포장에 마스터브랜드 분위기를 연결할 때
- Transformation: 별도 장식보다 라벨·박스·신문·용기 자체의 활자와 물성을 중심 오브젝트로 쓴다. 편집 이미지는 인쇄물의 정보 구조를 유지하는 범위에서 흑백 판화와 초현실 은유를 허용한다.
- Intended effect: 커뮤니케이션과 제품 세계가 같은 재료 논리를 공유한다.
- Evidence IDs: EV-006 EV-012 EV-040 EV-041
- Connected claim IDs: CL-005 CL-010 CL-014
- Confidence: high
- Alternative explanation: 특정 콘텐츠 형식의 영향일 수 있다.
- Exception and scope: 상태·액션 UI는 평면 컨트롤을 사용하며, 편집 판화를 모든 제품 사실 사진에 적용하지 않는다.
- Protected source expression: Le Journal 형식과 Le Labo 라벨 레이아웃은 복제하지 않는다.
- Acceptance test: 오브젝트 또는 인쇄 은유가 메시지 기능과 촉각적 매체 논리를 함께 가진다.
- Rejection test: 재료와 무관한 장식이 오브젝트보다 먼저 보인다.

## GK-05 — 반복을 한 번의 인간 행동으로 끊기

- Input condition: 같은 제품군의 일관성을 보여 주면서 사용 관계를 더할 때
- Transformation: 반복 실루엣과 라벨을 유지하고 선택·도포·묶기 같은 손동작 하나만 더한다.
- Intended effect: 체계를 보존하면서 화면에 시간과 목적을 만든다.
- Evidence IDs: EV-011 EV-016 EV-024
- Connected claim IDs: CL-008 CL-010
- Confidence: medium
- Alternative explanation: 컬렉션 타일의 단기 사진 스타일일 수 있다.
- Exception and scope: 완전한 PDP는 사람 없이 제품 사실을 우선하며, 서비스 단계는 손 대신 물체 상태의 연속으로도 행동을 설명한다.
- Protected source expression: 특정 손 포즈와 Le Labo 세트는 복제하지 않는다.
- Acceptance test: 제품군 차이와 한 사람의 행동이 동시에 읽힌다.
- Rejection test: 여러 손·소품이 라벨과 실루엣을 가린다.

## Contrasting qualities that stay together

1. 실험실의 정확성 / 시적 모호성
2. 산업적 반복 / 개인의 날짜와 표식
3. 거친 제작 현장 / 절제된 고급감

## Source expressions not to copy directly

1. Le Labo 워드마크, 라벨 레이아웃, 향명+숫자 체계
2. “We believe”와 “same bottle, same scent, same perfume” 문구
3. Le Journal 신문 형식, 고유 랩 명칭과 매장 트레이드 드레스
